# webm → mp3 変換

Jitsi Meet の録画ファイル（webm）から音声を取り出し、mp3 に変換するツールです。
会議の録画を音声だけにして、文字起こしや議事録作成、共有に使う用途を想定しています。

変換はすべて**ブラウザ内（ffmpeg.wasm）**で行います。録画ファイルが外部のサーバーに送られることはありません。

## 特長

- webm（動画・音声のみ、どちらも可）から音声を抽出して mp3 に変換
- ビットレートを選択可能（128 / 192 / 256 / 320 kbps、既定は 192）
- 読み込み時に音声の波形を自動で表示。波形をドラッグして、変換する範囲を直感的に選択できる
- 開始・終了時間を指定して、必要な部分だけを変換（波形での選択と相互に連動）
- ドラッグ&ドロップで読み込み、進捗表示、変換の中止
- 入力ファイルをメモリにコピーしない（WORKERFS）ため、大きなファイルでも余裕がある
- 変換中に外部と通信しない。機密性のある会議録画も扱える

## 使い方

1. 画面に webm ファイルをドラッグ&ドロップする（クリックして選択も可）
2. 波形が表示されるのを待つ（長い録画では少し時間がかかる。待たずに「中止」して変換することも可能）
3. 必要ならビットレートや、変換する範囲を指定する
   - 波形をドラッグすると範囲を選択できる（クリックで解除）。開始・終了時間の欄にも反映される
   - 波形は拡大縮小できる。ホイールでカーソル位置を中心に拡大縮小、Shift+ホイールで左右に移動する。「＋」「－」「全体」「選択範囲へ」のボタンや、波形下のスクロールバー（つまみの長さが表示中の割合）も使える
   - 「▶ 再生」で、読み込んだ録画の音声を再生できる（波形にフォーカスしてスペースキーでも可）。範囲を選択していれば、その範囲だけを再生して終端で止まる。変換する前に、選んだ範囲を聞いて確認できる
   - 波形をクリックすると、その位置に再生位置（黄色の線）を移す。範囲の選択は解除される
   - 拡大したままドラッグ選択するとき、ポインタを波形の左右の端に寄せる（はみ出す）と、自動でスクロールして選択を広げられる
   - 波形にフォーカスすると、`+` `-` `0` キーで拡大縮小・全体表示、左右キーで移動できる
   - 時間を直接入力してもよい。`90`、`1:30`、`0:01:30` のような形式で、波形の選択にも反映される
   - 空欄なら、最初から・最後まで
4. 「mp3に変換」を押す
5. 完了したら、表示されたボタンから mp3 をダウンロードする

## 起動方法

### A. デスクトップアプリ（WebView2 版・Windows）

`WebmMp3.exe` を実行するだけで使えます。サーバーの起動は不要です。

**必要なもの**
- .NET 8 デスクトップランタイム
- Microsoft Edge WebView2 ランタイム（Windows 11 は標準搭載）

> ネットワーク共有上の exe は、.NET のセキュリティ制限で動かないことがあります。各自の PC のローカルにコピーして実行してください。

**ビルド方法**

```powershell
npm ci
cd app
dotnet publish -c Release -r win-x64 --self-contained false -o publish
```

`app\publish\` に出力されます。配布するときは、このフォルダ一式を渡します。

### B. ローカルサーバー（ブラウザ版）

```powershell
npm ci
npm start
```

ブラウザで http://127.0.0.1:8080/ を開きます。

> `index.html` を直接ダブルクリックしても動きません（ブラウザが ES モジュールと Worker の読み込みを制限するため）。

### C. 社内の Web サーバーに置く

`public/` と ffmpeg のファイル（`node_modules/@ffmpeg/ffmpeg/dist/esm/` と `node_modules/@ffmpeg/core/dist/esm/`）を、次の構成で配置します。

```
/                          ← public/ の中身
/vendor/ffmpeg/            ← @ffmpeg/ffmpeg の dist/esm/*.js
/vendor/core/              ← ffmpeg-core.js と ffmpeg-core.wasm
```

- シングルスレッド版のため、COOP/COEP などの特別なヘッダは不要です。
- IIS では、`.wasm` の MIME 型（`application/wasm`）の追加が必要です。

## 制限事項・注意

- **音声トラックがない webm は変換できません。** 画面録画で音声を共有していないファイルなどが該当し、その旨がエラーで表示されます。
- **大きなファイルはメモリ不足で失敗することがあります。** 目安は 1GB 程度までです。1GB を超えると警告を表示します。
  - 長時間の会議でも、音声のみの録画なら小さく済みます。映像入りの録画は、サイズが大きくなりがちです。
- 録画の作成方法によっては、録画時間などのメタデータが入っていないことがあります。その場合、進捗バーが動かない、または開始・終了時間の指定がずれることがあります。
- 対応ブラウザは、最新の Chrome / Edge です（WebAssembly が必要）。
- 同時に複数のファイルを変換することはできません。1 ファイルずつ変換します。


## 依存関係とセキュリティ方針

依存は最小限に絞り、版を固定しています。

| 依存 | 版 | 用途 |
|---|---|---|
| `@ffmpeg/ffmpeg` | 0.12.15 | ffmpeg.wasm の JS ラッパー |
| `@ffmpeg/core` | 0.12.10 | ffmpeg 本体（wasm） |
| `Microsoft.Web.WebView2` | 1.0.4191.47 | WebView2 版のみ |

- `^` などの範囲指定は使わず、`package-lock.json` をコミットしています。更新するときは、内容を確認してから版を上げてください。
- wasm と JS はすべて自前で配信し、外部の CDN には依存しません。実行時に外部へ通信する処理はありません。
- WebView2 版は、アプリ内のホスト（`app.local`）以外への遷移と、新規ウィンドウを禁止しています。
